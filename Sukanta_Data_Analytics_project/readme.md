# Car Sales Data Analysis

## Project Overview

This project analyzes car sales data using Python and provides insights through data analysis and visualization.

The project explores relationships between car sales and different factors such as company, year, fuel type, transmission, mileage, and engine capacity.

## Dataset

The dataset contains information about cars and includes the following columns:

* Car_Name
* Company
* Year
* sale
* Fuel_Type
* Transmission
* Mileage
* Engine_CC

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

The project includes:

* Dataset inspection
* Missing-value checking
* Descriptive statistics
* Total and average sales analysis
* Sales by fuel type
* Sales by transmission type
* Sales by company
* Year vs. sales analysis
* Engine capacity vs. sales analysis
* Mileage vs. sales analysis
* Correlation analysis
* Data visualization

## How to Run

1. Install Python 3.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Open `sales_Analysis.ipynb` in Jupyter Notebook or VS Code.
4. Select the appropriate Python kernel.
5. Run all notebook cells.

## Conclusion

This project demonstrates how Python-based data analysis can be used to explore car sales data and identify patterns and relationships among different variables.
